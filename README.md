# j8b Add-ons for Home Assistant

**j8b** — evini tek yerden yönet, verin evde kalsın. https://j8b.net

## Kurulum
1. Home Assistant → Ayarlar → Eklentiler → Eklenti Mağazası → sağ üst ⋮ → **Depolar**
2. Şu adresi ekle: `https://github.com/sezaicetin/j8b-addons`
3. Listede **j8b** eklentisini aç → Kur → Yapılandırma'ya j8b uygulamasındaki 8 haneli eşleştirme kodunu yaz → Başlat.

Hazır imajlar `ghcr.io/sezaicetin/j8b-{aarch64,amd64}` — cihazda derleme yapılmaz.
