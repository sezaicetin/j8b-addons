# j8x Add-ons for Home Assistant

**j8x** — evini tek yerden yönet, verin evde kalsın. https://j8b.net

## Kurulum
1. Home Assistant → Ayarlar → Eklentiler → Eklenti Mağazası → sağ üst ⋮ → **Depolar**
2. Şu adresi ekle: `https://github.com/sezaicetin/j8x-addons`
3. Listede **j8x** eklentisini aç → Kur → Yapılandırma'ya j8x uygulamasındaki 8 haneli eşleştirme kodunu yaz → Başlat.

Hazır imajlar `ghcr.io/sezaicetin/j8x-{aarch64,amd64}` — cihazda derleme yapılmaz.
